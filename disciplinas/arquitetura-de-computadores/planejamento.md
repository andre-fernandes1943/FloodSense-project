# Arquitetura de Computadores - FloodSense

Este diretório contém as informações relacionadas à infraestrutura computacional utilizada pela equipe FloodSense durante o desenvolvimento do projeto.

---

## Sistemas Operacionais Utilizados

A empresa utiliza diferentes sistemas operacionais para desenvolvimento, testes e organização do projeto:

- Windows 11
- Linux Mint

A utilização de múltiplos sistemas permitiu maior flexibilidade no desenvolvimento da plataforma, compatibilidade entre ferramentas e melhor organização do ambiente de trabalho.

---

## Equipamentos Utilizados

A equipe utiliza notebooks Lenovo ThinkPad T14 para desenvolvimento das atividades da empresa.

### Configurações utilizadas

- Processadores Intel Core i5 e Intel Core i7
- 16GB de memória RAM
- SSD de 512GB
- Tela Full HD
- Conectividade Wi-Fi e Bluetooth

---

## Ferramentas Utilizadas

Durante o desenvolvimento do projeto, foram utilizadas ferramentas como:

- Visual Studio Code
- GitHub
- Tinkercad
- Google Drive
- Canva

---

## Objetivo da Infraestrutura

A infraestrutura computacional utilizada pela FloodSense foi organizada para garantir desempenho, estabilidade e suporte ao desenvolvimento da solução tecnológica proposta pela equipe.
