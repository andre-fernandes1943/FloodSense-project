# Sistema IoT - FloodSense

Esta pasta contém a estrutura do sistema IoT desenvolvido para o projeto FloodSense, responsável pelo monitoramento do nível da água em áreas de risco.

O circuito foi desenvolvido utilizando Arduino Uno R3 como base principal do sistema, realizando a leitura dos sensores e o controle dos componentes de alerta e exibição de informações.

## Componentes Utilizados

### Arduino Uno R3
Responsável pelo processamento das informações e controle do sistema.

### Ultrasonic Distance Sensor
Sensor utilizado para medir a distância entre o dispositivo e o nível da água, permitindo identificar possíveis situações de risco.

### LCD 16x2
Display responsável pela exibição das informações do sistema em tempo real.

### 2 LEDs
Utilizados como alerta visual para representar diferentes estados do monitoramento.

### 2 Resistores
Componentes auxiliares utilizados no controle elétrico do circuito.

## Objetivo

O objetivo do sistema é realizar o monitoramento contínuo do nível da água e representar de forma prática e visual, como uma solução IoT pode auxiliar na prevenção de enchentes e emissão de alertas preventivos.
