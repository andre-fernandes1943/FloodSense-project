# UX/UI - FloodSense 2.0

## Prototipação

Nesta parte do projeto estou responsável pela prototipação das telas do FloodSense 2.0.

O objetivo é mostrar de forma visual como o usuário vai interagir com o aplicativo, buscando deixar as telas simples, organizadas e fáceis de entender.

Para os protótipos estou seguindo as funcionalidades que foram definidas para o projeto e mantendo a identidade visual do FloodSense, principalmente com os tons de azul e detalhes em laranja.

## Tela de Login

A primeira tela desenvolvida foi a tela de login. Ela representa o primeiro acesso do usuário ao aplicativo.

Nela temos os campos de e-mail e senha, o botão "Entrar" e a opção "Criar cadastro" para novos usuários.

O protótipo mantém a identidade visual do FloodSense e servirá como base para o desenvolvimento das próximas telas do aplicativo.
