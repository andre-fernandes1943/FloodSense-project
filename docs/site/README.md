# Site Oficial — FloodSense

Este diretório contém as informações relacionadas ao site oficial da FloodSense.

## Acessar Plataforma

🔗 Link do site publicado:  
https://andre-fernandes1943.github.io/FloodSense-project/

---

O site apresenta:
- informações sobre a empresa;
- funcionamento da solução IoT;
- sistema de monitoramento;
- cadastro de usuários;
- Página de confirmação de cadastro;
- integração com API de CEP;

---

## API Utilizada

O sistema utiliza a API pública ViaCEP para preenchimento automático de endereço através do CEP informado pelo usuário.

🔗 https://viacep.com.br/
